Frontend SmartLogix

Frontend del sistema SmartLogix, desarrollado con React, TypeScript y Vite. Esta aplicación permite visualizar y gestionar módulos logísticos como pedidos, inventario y envíos mediante una interfaz web organizada, responsiva y conectada al backend a través de API REST.

Objetivo del proyecto

El objetivo del frontend es entregar una interfaz clara y funcional para que los usuarios puedan interactuar con los procesos principales de SmartLogix, tales como:

- Gestión de pedidos.
- Validación y asignación de pedidos.
- Visualización de inventario.
- Visualización de envíos.
- Navegación entre módulos mediante rutas.
- Comunicación con backend mediante API Gateway.

Tecnologías utilizadas

- React
- TypeScript
- Vite
- React Router DOM
- NPM
- CSS

Ejecutar: 
"npm run dev"

y funcionara en el host 5173
